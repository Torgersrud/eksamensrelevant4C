### **Problem 1**

Let $f(x)$ the $2\pi$-periodic function defined by

$$f(x)=\left\{\begin{array}{ll}-\sin(x)&\text{if }-\pi<x\le 0,\\ \sin(x)&\text{if }0<x\le\pi.\end{array}\right.$$

**a)** Compute the Fourier series of the function $f(x)$.

**b)** Use the Fourier series of the function $f(x)$ computed in exercise **a)** to find the value of the serie

$$\sum_{n=1}^{\infty}\frac{1}{4n^2-1}$$
