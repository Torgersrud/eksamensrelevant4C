b) Dersom vi antar at $f(x) = \frac{1}{2} (f(x+0) + f(x-0))$, har vi

$$f(x) = \frac{2\sqrt{2}}{\pi} \left( \frac{\sin(\frac{\pi}{2}x)}{1} - \frac{\sin(\frac{3\pi}{2}x)}{3} - \frac{\sin(\frac{5\pi}{2}x)}{5} + \frac{\sin(\frac{7\pi}{2}x)}{7} + \frac{\sin(\frac{9\pi}{2}x)}{9} - \cdots \right).$$

Setter vi $x = 1$ får vi

$$1 = \frac{2\sqrt{2}}{\pi} \left( \frac{1}{1} + \frac{1}{3} - \frac{1}{5} - \frac{1}{7} + \frac{1}{9} + \frac{1}{11} - \cdots \right) = \frac{2\sqrt{2}}{\pi} S_1.$$

Altså er

$$S_1 = \frac{\pi}{2\sqrt{2}}.$$

Setter vi $x = \frac{1}{2}$ får vi

$$\frac{1}{2} = \frac{2\sqrt{2}}{\pi} \frac{\sqrt{2}}{2} \left( \frac{1}{1} - \frac{1}{3} + \frac{1}{5} - \frac{1}{7} + \frac{1}{9} - \frac{1}{11} + \cdots \right) = \frac{2}{\pi} S_2.$$

Altså er

$$S_2 = \frac{\pi}{4}.$$
