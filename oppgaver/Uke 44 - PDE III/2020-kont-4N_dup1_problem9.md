### **Problem 9** [10 points]

Recall the following difference formula for a four times continuously differentiable function $f\colon\mathbb{R}\to\mathbb{R}$:

$$f''(a)\text{ can be approximated by }\frac{f(a+h)-2f(a)+f(a-h)}{h^{2}}.$$

Assume that $|f^{(4)}(x)|\leq 1$ for all $x\in\mathbb{R}$. Use fourth order Taylor expansion to show the following error estimate

$$\Big|f''(a)-\frac{f(a+h)-2f(a)+f(a-h)}{h^{2}}\Big|\leq\frac{h^{2}}{12}.$$
