### **Oppgave 2**

Funksjonen $f$ er definert ved at følgende betingelser er oppfylt.

i) $\quad f(x) = f(-x)$ for alle reelle $x$.

ii) $\quad f(x) = f(x+4)$ for alle reelle $x$.

iii) $\quad f(x) = 1 - x$ for $0 < x < 2$.

a) Skisser grafen til $f$ for $-2 < x < 6$, og finn Fourier-cosinusrekka til $f$.

b) Løs varmeligningen $\quad u_t = u_{xx}$ $\ $ i området $\quad 0 < x < 2 \quad$ og $\quad t > 0 \quad$ med randverdiene $\quad u_x(0,t) = u_x(2,t) = 0 \quad$ og initialbetingelsen $\quad u(x,0) = 1 - x \quad$ for $\quad 0 < x < 2$.
