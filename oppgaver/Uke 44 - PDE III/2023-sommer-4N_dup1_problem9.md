### **Problem 9.** (Numerical Solution of PDEs)

Consider the heat equation

$$u_t(x, t) = \frac{1}{4} u_{xx}(x, t) \qquad \text{for } 0 \leq x \leq 1 \text{ and } t \geq 0,$$

with boundary conditions

$$u(0, t) = \cos(t), \quad u(1, t) = 0, \qquad \text{for } t \geq 0,$$

and initial condition

$$u(x, 0) = 1 - x \qquad \text{for } 0 \leq x \leq 1.$$

Set up an explicit finite difference scheme for this equation. Use the step length $h = 0.25$ in the spatial direction, and the step length $k = 0.1$ in the temporal direction.

Use your finite difference scheme in order to find an approximation to $u(0.25, 0.2)$.
