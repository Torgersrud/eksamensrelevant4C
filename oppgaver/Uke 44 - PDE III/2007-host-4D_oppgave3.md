### **Oppgave 3**

I denne oppgaven skal vi betrakte kontinuerlige funksjoner som tilfredsstiller varmeligningen

$$(1) \qquad u_t = u_{xx}$$

i området $0 < x < \pi$, $\quad 0 < t < \infty$, og som i tillegg tilfredsstiller randbetingelsen

$$(2) \qquad u_x(0,t) = u_x(\pi,t) = 0.$$

a) Finn alle funksjoner $u$ av formen $u(x,t) = F(x)G(t)$ som tilfredsstiller (1) og (2).

b) Bestem funksjonen $u(x,t)$ som tilfredsstiller (1) og (2), samt initialbetingelsen

$$(3) \qquad u(x,0) = \pi - x \quad \text{for} \quad 0 \leq x \leq \pi.$$
