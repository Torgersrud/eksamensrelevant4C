### **Problem 4** **Classification and Verification of PDEs (9 points)**

a) Classify the following two PDEs with respect to linearity, homogeneity and order.

1) $\frac{\partial^3}{\partial t^3}u=\frac{\partial^2}{\partial x^2}u+\frac{\partial^2}{\partial y^2}u+u^2$

2) $\frac{\partial}{\partial t}u=-\frac{\partial^4}{\partial x^4}u+\frac{\partial^2}{\partial x^2}u+u+x+t$

b) For the given PDE
$$\begin{cases}\frac{\partial^3}{\partial t^3}u=\frac{1}{2}\frac{\partial^2}{\partial x^2}u,&\text{for }-\pi\le x\le\pi,\,t>0,\\ u(-\pi,t)=u(\pi,t)=0,&\text{for }t>0,\end{cases}$$
you are given the following candidate for a solution
$$u(x,t)=e^{-2t}\sin(4x).$$
Check whether this is a solution for the PDE.
Is this the only solution of this PDE?
