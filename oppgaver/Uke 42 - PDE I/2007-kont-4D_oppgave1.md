### **Oppgave 1**

a) Finn Fourier-sinusrekken og finn Fourier-cosinusrekken til funksjonen

$$f(x) = \sin \pi x \quad \text{for} \ \ 0 \leq x \leq 1.$$

Du vil få bruk for

$$\sin n\pi x \cos m\pi x = \frac{1}{2}(\sin(n-m)\pi x + \sin(n+m)\pi x)$$

b) Finn alle løsninger på formen $u(x,y) = F(x)G(y)$ av randverdifproblemet

$$\frac{\partial^2 u}{\partial x^2} + \frac{\partial^2 u}{\partial y^2} = u \quad \text{for} \ \ 0 \leq x \leq 1, \ \ 0 \leq y \leq 1$$

$$u_x(0,y) = u_x(1,y) = 0 \quad \text{for} \ \ 0 < y < 1.$$

c) Finn den løsningen av randverdifproblemet i b) som også tilfredsstiller randkravene

$$u(x,0) = \sin \pi x, \quad u(x,1) = 0 \quad \text{for} \ \ 0 < x < 1.$$
