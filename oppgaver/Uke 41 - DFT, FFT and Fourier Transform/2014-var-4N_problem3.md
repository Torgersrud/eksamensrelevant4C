### **Problem 3**

By using Fourier transform, determine the function $u(t,x)$ that satisfies the following partial differential equation:

$$u_{t}-u_{xx}+u=0,\quad x\in\mathbb{R},\quad t>0,$$

$$\left.u\right|_{t=0}=u_{0},\quad x\in\mathbb{R},$$

where $u_{0}(x)$ is a given function.
