### **Problem 5**

**a)** Find the polynomial $p_{2}(x)$ which interpolates

$$\begin{array}{c|ccc}x_{k}&-2&-1&2\\ \hline f_{k}&-13&-5&7\end{array}$$

using Lagrangian interpolation.

**b)** We then add another datapoint. We now want to find the polynomial $p_{3}(x)$ of the lowest possible degree which interpolates the data set

$$\begin{array}{c|cccc}t_{k}&-2&-1&2&3\\ \hline f_{k}&-13&-5&7&4\end{array}.$$

You can choose how you find this polynomial yourself.
