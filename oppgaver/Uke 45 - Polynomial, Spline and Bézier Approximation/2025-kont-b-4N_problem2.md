### **Problem 2** **Interpolation (10 points)**

The following table shows the values of a function $f(x)$ at the following points:

$$\begin{array}{|c|c|}\hline x&f(x)\\\hline 1&2\\\hline 2&8\\\hline 3&18\\\hline 4&32\\\hline\end{array}$$

a) Construct an interpolating polynomial $p(x)$ of minimal necessary degree for the given data using the Lagrange interpolation formula. Simplify the resulting polynomial as much as possible.

b) Use $p(x)$ to compute an approximate value of $f(2.5)$.

c) Briefly explain why the interpolating polynomial of minimal necessary degree exists and is unique for this data set.
