### **Problem 8.** (Solution to a PDE)

The equation

$$\frac{\partial^2 u}{\partial t^2} + 7u = \frac{\partial^2 u}{\partial x^2} \qquad \text{for } 0 < x < \pi \text{ and } t > 0$$

with boundary conditions

$$u(0, t) = 0 \qquad \text{and} \qquad u(\pi, t) = 0 \qquad \text{for } t > 0$$

has the general solution

$$u(x, t) = \sum_{n=1}^\infty \sin(nx) \left( A_n \cos\left( t \sqrt{7 + n^2} \right) + B_n \sin\left( t \sqrt{7 + n^2} \right) \right).$$

(You don't have to show this!)

Use this information to find the solution that additionally satisfies the initial conditions

$$u(x, 0) = \sin(x) \qquad \text{and} \qquad \frac{\partial u}{\partial t}(x, 0) = 2 \sin(3x) \qquad \text{for } 0 < x < \pi \, .$$
